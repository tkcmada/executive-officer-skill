# executive-officer-skill

複数の並行エージェントセッション (peer) を束ねて、技術的な中身を理解した上で判断を代行する
「司令塔」役のスキル/規範集。決定論的な監視・自動継続オーケストレーション (「止まっていない
か」を機械的に見張る層) とは別の層として、**解釈が要る技術判断**を担う。

## 構成

```
SKILL.md    スキル定義 (位置づけ / 可逆性テスト / 基本ループ / 通信作法 / 生存確認)
```

## コアアイデア: 可逆性テスト

peerから相談が来たら、次の2点だけで自律決定かエスカレーションかを仕分ける:

1. **可逆か** (バージョン管理下で後から戻せるか)
2. **外部/費用に影響するか** (発注・決済・安全マージン・方針選択を伴うか)

①YES・②NO なら自分で決めて前に進める。②YESなら選択肢+推奨を添えて最終責任者へ上げる。
「任されたから何でも自分で決める」でも「少しでも迷ったら全部エスカレーション」でもない、
中間の規律。

## 由来

複数エージェントセッションが並行してハードウェア設計 (複数基板からなる1つの機体) を進める
実プロジェクトで、複数日間にわたり実際にこの役割を担った経験から抽出した。詳細は SKILL.md 参照。

## 使い方

Claude Code等、skillの概念をサポートするエージェント実行環境で、このリポジトリの内容を
skillディレクトリに配置する。トリガー語 (「executive officer」「XO」等) で発火するか、
複数の並行セッションを束ねて技術判断を代行する場面で参照する。
